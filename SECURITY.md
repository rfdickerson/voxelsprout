# Security reporting

Game archives, plugins, meshes and scripts are untrusted input. Parser crashes,
out-of-bounds accesses and sandbox escapes are security-relevant.

Use the repository host’s private vulnerability reporting feature when available.
Do not attach proprietary game data, private saves or exploitable payloads to a
public issue. If private reporting is unavailable, open an issue requesting a
private contact without exploit details. No response-time commitment is established.

Include the engine revision, operating system, affected format, and preferably a
small synthetic reproducer. Only the current development branch is maintained.
