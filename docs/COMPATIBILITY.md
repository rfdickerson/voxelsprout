# Compatibility

| Area | Current contract |
|---|---|
| Linux x86-64 | Primary build platform; packaged release qualification pending |
| Skyrim SE + JK’s Skyrim 1.7 + SMIM SE 2.08 Everything | Target gameplay slice; continuous route blocked |
| Skyrim full game / arbitrary mods | Not release-qualified |
| Morrowind, Oblivion, Fallout 3/New Vegas | Experimental import/exploration; no full-game completion claim |
| ODAI saves | Checksummed native saves, previous generation retained |
| Skyrim `.ess`, SKSE, DLL mods | Unsupported |
| Inventory, journal, world map | Implemented subsets; see runtime reference |
| English content | Initial slice baseline; other languages unverified |
| Windows | Future work; no first-release package |

Import success, script-fragment tests, and screenshots do not prove a playable
quest. The authoritative route blockers remain in SKYRIM_FIRST_RUNTIME.md.
